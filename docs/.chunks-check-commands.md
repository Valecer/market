# Команды для проверки активных чанков

## 1. Логи контейнера (активные чанки в реальном времени)
```bash
docker logs -f --tail 100 marketbel-ml-analyze | grep -i "chunk\|extracting\|llm_extractor"
```

## 2. Проверка в базе данных - недавние чанки
```bash
docker exec -it marketbel-postgres psql -U marketbel_user -d marketbel -c "
SELECT 
    task_id,
    chunk_id,
    extraction_phase,
    error_type,
    row_number,
    created_at
FROM parsing_logs 
WHERE chunk_id IS NOT NULL 
  AND created_at > NOW() - INTERVAL '1 hour'
ORDER BY created_at DESC 
LIMIT 20;"
```

## 3. Статистика по чанкам (последний час)
```bash
docker exec -it marketbel-postgres psql -U marketbel_user -d marketbel -c "
SELECT 
    chunk_id,
    extraction_phase,
    COUNT(*) as log_count,
    MIN(created_at) as first_log,
    MAX(created_at) as last_log
FROM parsing_logs 
WHERE chunk_id IS NOT NULL 
  AND created_at > NOW() - INTERVAL '1 hour'
GROUP BY chunk_id, extraction_phase
ORDER BY chunk_id DESC;"
```

## 4. Поиск медленных чанков в логах
```bash
docker logs marketbel-ml-analyze 2>&1 | grep -i "chunk_critical_slow\|llm_time_seconds" | tail -10
```

## 5. Активные задачи в Redis
```bash
docker exec -it marketbel-redis redis-cli -a "${REDIS_PASSWORD:-dev_redis_password}" KEYS "job:*"
```

## 6. Детали конкретной задачи из Redis
```bash
# Сначала найдите job_id (из команды выше)
docker exec -it marketbel-redis redis-cli -a "${REDIS_PASSWORD:-dev_redis_password}" HGETALL "job:ВАШ_JOB_ID"
```
